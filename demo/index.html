Điều khiển Pipeline Execution
Phase 1: Baseline Data Pipeline (7 Steps)
1
Fetch Raw Records from Source API Role 2
Truy vấn Crossref REST API với HTTP retry & exponential backoff strategy (tối đa 3 lần). Fallback snapshot nếu network bị gián đoạn.
src/ingestion/crossref.py fetch_source_records()
2
Data Cleaning & Preprocessing Role 2
Chuẩn hóa khoảng trắng, parse ngày tháng, tính toán age_days, loại bỏ bản ghi rỗng/trùng lặp paper_id và title. Tạo trường text_for_embedding.
src/ingestion/cleaning.py build_clean_dataframe()
3
Build ChromaDB Vector Index Role 3
Vectorize clean text bằng sentence-transformers/all-MiniLM-L6-v2 và lưu vào ChromaDB collection 'papers-baseline'.
src/retrieval/index.py LocalEmbeddingIndex.build()
4
Generate Evaluation Test Set Role 4
Tạo tự động 60 Q&A evaluation pairs từ tập dữ liệu sạch để đánh giá chất lượng RAG retrieval và answer generation.
src/evaluation/testset.py build_test_set()
5
Evaluate Retrieval & Answer Quality Role 4
Tính toán các chỉ số Retrieval Hit Rate, Mean Token F1, LLM Judge Accuracy và Mean Judge Score trên tập testset.
src/evaluation/metrics.py evaluate_pipeline()
6
Data Observability & Freshness Checks Role 4
Thực thi 6 data quality checks (null check, duplicates, short summary, freshness) và tạo báo cáo freshness report.
src/observability/quality.py run_data_quality_checks()
7
Generate Phase 1 Report Role 1
Tổng hợp toàn bộ cấu hình, kết quả metrics và observability status xuất ra file report phase1_report.md.
src/observability/reporting.py generate_phase1_report()
Phase 2: Corruption, Repair & Comparison Pipeline (10 Steps)
1
Verify Baseline & Load Clean Dataset Role 1
Đọc kết quả baseline metrics và clean dataset JSON để làm mốc đối chứng cho quá trình gây lỗi.
src/pipelines/corruption_flow.py
2
Simulate Data Corruption Scenarios Role 2
Gây 6 loại lỗi chủ động: drop records, blank summary, inject noise, truncate title, stale date, duplicate rows.
src/ingestion/corruption.py corrupt_clean_dataframe()
3
Build Corrupted Chroma Index Role 3
Tạo vector index mới từ tập dữ liệu đã bị biến đổi/lỗi để mô phỏng suy giảm chất lượng tìm kiếm RAG.
src/retrieval/index.py
4
Evaluate Corrupted Pipeline Role 4
Đo lường mức độ suy giảm performance (Hit Rate giảm từ 100% xuống 80%, F1 giảm 22%).
src/evaluation/metrics.py
5
Observability Detection on Corrupted Data Role 4
Hệ thống Observability bắt lỗi thành công: Quality status chuyển FAILED (phát hiện duplicates, short summaries, stale rows).
src/observability/quality.py
6
Data Repair & Re-ingestion Role 2
Khôi phục pipeline bằng cách đọc lại snapshot gốc uy tín (raw_records.json) và thực thi lại cleaning process.
src/ingestion/crossref.py load_raw_records()
7
Build Repaired Vector Index Role 3
Rebuild lại ChromaDB vector index hoàn toàn từ tập dữ liệu đã được làm sạch và sửa lỗi.
src/retrieval/index.py
8
Evaluate Repaired Pipeline Role 4
Xác nhận các chỉ số khôi phục hoàn toàn về mức tối ưu (Hit Rate: 1.000, F1: 1.000, Judge Accuracy: 1.000).
src/evaluation/metrics.py
9
Observability Verification on Repaired Data Role 4
Chạy lại quality & freshness checks: Hệ thống chuyển trạng thái PASSED và FRESH hoàn toàn.
src/observability/quality.py

Generate Comparison Report Role 1
